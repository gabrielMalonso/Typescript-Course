# Capítulo 03: Operadores e Estruturas Condicionais

## Módulo 1 — Fundamentos Absolutos

## Objetivos

Ao concluir este capítulo, você será capaz de:

- calcular resultados com operadores aritméticos e precedência consciente;
- atualizar variáveis com operadores de atribuição;
- produzir valores booleanos com comparações estritas;
- combinar condições com `&&`, `||` e `!`;
- escolher caminhos com `if`, `else if`, `else`, ternário e `switch`;
- reconhecer valores truthy e falsy;
- usar `??` para valores ausentes e reconhecer a finalidade de `?.`;
- decompor uma regra real em dados, condições e ações.

## Por que os temas foram unidos

Operadores criam resultados e condições; estruturas condicionais usam essas condições para decidir o que executar. Estudá-los juntos permite aplicar cada operador imediatamente, sem um capítulo intermediário apenas de sintaxe.

```text
DADOS → OPERADORES → CONDIÇÃO → CAMINHO EXECUTADO
```
