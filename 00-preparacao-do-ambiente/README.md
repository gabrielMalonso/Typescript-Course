# Capítulo 00: Preparação do Ambiente

## Módulo 1 - Fundamentos Absolutos

---

## Objetivos

Ao concluir este capítulo, você será capaz de:

- Entender o que é programação e TypeScript
- Explicar as diferenças entre TypeScript e JavaScript
- Ter um ambiente de desenvolvimento funcionando
- Criar, compilar e executar programas TypeScript
- Usar o watch mode para desenvolvimento ágil
